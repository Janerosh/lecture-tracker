# Трекер просмотренных занятий

Я смотрю записи лекций и семинаров не сразу и отмечаю в заметках, что уже посмотрено. Программа сверяет заметки с расписанием и показывает долги — занятия, которые ещё не посмотрены.

## Как запустить

Из папки проекта:

```
python3 main.py
```

Сейчас программа выводит список занятий, которые по расписанию уже прошли.

## Файлы

- `main.py` — точка входа: читает расписание, проверяет его и печатает результат.
- `schedule.py` — всё про расписание: чтение файла, проверка ошибок, список прошедших занятий.
- `schedule.json` — расписание: даты начала и конца семестра, в какие дни недели какие занятия, какие даты отменены. Пока расписание выдуманное, потом заменю на настоящее.
- `example_notes.txt` — пример заметок. Строки выдуманные, но в том же формате, что и настоящие.
- `data/` — настоящие заметки и память программы. Папка не попадает в git (см. `.gitignore`).

## Формат заметок

Одна строка — одно занятие: тип, дата (день и месяц) и отметка.

```
семинар 13 10 посмотрела
лекция 0509 не успела
```

## Краевые случаи

- Сегодняшние занятия ещё не считаются прошедшими: запись могла не успеть появиться.
- Отменённые даты (праздники) пропускаются — в этот день не будет ни одного занятия.
- В один день может быть несколько занятий (в среду лекция и семинар).
- Ошибки в `schedule.json` (нет поля, дата не в том формате, непонятный день недели, сломанный JSON) не роняют программу: она перечисляет, что не так, и останавливается.
